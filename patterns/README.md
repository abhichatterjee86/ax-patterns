# The patterns

50 AI interaction patterns, 1 Markdown file each, in the 7 moments of a conversation. Each file has the story, every state over time, every device, when to use it and when not to, anatomy, do and avoid, writing and accessibility notes, products it was seen in, related patterns and sources.

The same pages, with live demos: https://axpatterns.design/patterns. The whole library in 1 file: [ax-patterns-full.md](ax-patterns-full.md).

Text and figures are CC BY 4.0 - quote them, teach from them, build on them, with credit and a link. Pattern IDs never change.
