# Prompts

Ready-to-paste prompts for ChatGPT, Claude, Gemini, Copilot or any chat AI. No install needed: copy the prompt, paste it, and attach or paste your own material where it says so.

Each prompt tells the AI to read the patterns from https://axpatterns.design (every pattern is also plain Markdown at `https://axpatterns.design/patterns/<slug>/markdown`, and the whole library is 1 file at `https://axpatterns.design/llms-full.txt`). If your AI tool cannot open links, paste the pattern files from [../patterns](../patterns) instead.

| Prompt | Use it when |
|---|---|
| [critique-my-ai-flow.md](critique-my-ai-flow.md) | You have screens, a prototype or a description of an AI feature and want a review |
| [pick-patterns-for-my-product.md](pick-patterns-for-my-product.md) | You are starting an AI feature and want to know which patterns it needs, in order |
| [write-the-waiting-states.md](write-the-waiting-states.md) | You need the loading, thinking, streaming, stop and error states written out |
| [design-an-approval-gate.md](design-an-approval-gate.md) | Your agent sends, pays, deletes or publishes, and you need the ask-before-acting flow |
| [write-ai-ux-copy.md](write-ai-ux-copy.md) | You need the strings: buttons, placeholders, statuses, errors, labels |
| [accessibility-check.md](accessibility-check.md) | You want an AI feature checked against the patterns' accessibility rules |
